# Шлях до 1 000 000 ₴

Україномовний фінансовий PWA-застосунок для GitHub Pages. HTML/CSS/JS без зовнішніх бібліотек; приватна синхронізація через Supabase Auth та базу даних із перевіркою власника (RLS).

Публічна версія починається з порожнього балансу. Особисті дані вводяться або імпортуються лише у браузері. Чистий капітал обчислюється після підтвердження активів і повноти списку боргів.

## Публікація

Завантажте файли в корінь гілки main. У Settings → Pages виберіть Deploy from a branch → main → / (root) → Save. Відкрийте адресу після завершення розгортання.

## Дані

Без входу записи зберігаються в localStorage конкретного браузера. Після входу через лист і першого вибору джерела збережені записи синхронізуються; planningDrafts та тема залишаються локальними. Зміни планування впливають на хмарні дані тільки після «Зберегти». Конфлікт версій вимагає вибору користувача. За наявності локальної чернетки хмарне оновлення очікує її збереження або скасування.

У розділі Дані доступні імпорт, експорт JSON і друк звіту. Перед першою синхронізацією спочатку експортуйте JSON на пристрої з актуальними даними. На іншому пристрої виберіть хмарну копію. Не завантажуйте особисті JSON-копії до репозиторію. Локальна резервна копія перед синхронізацією доступна окремою кнопкою. Вихід з акаунта зупиняє синхронізацію, але залишає локальні записи на пристрої.

Ключ sb_publishable у cloud.js призначений для браузера. Серверні ключі та паролі у файлах відсутні. Не послаблюйте політики RLS. Доступ до фінансової таблиці анонімним користувачам заборонений. Публічний код не містить адреси власника та фінансових записів.

## PWA

Маніфест і service worker підтримують офлайн-роботу після першого відкриття через HTTPS. Встановлення залежить від браузера. Використовуйте постійну адресу без параметра v. update.js перевіряє version.txt при запуску, поверненні до вкладки, відновленні мережі та кожні 60 секунд. Нова версія спершу завантажує весь набір файлів, потім чекає завершення редагування і хмарного запису. Локальне сховище не очищається; перед перезапуском зберігається вибраний розділ, місяць і позиція прокрутки. Без інтернету залишається поточна версія.

Для кожного випуску збільшуйте числовий номер одночасно у version.txt, meta app-version та посиланнях на JS/CSS в index.html, VERSION та ASSETS у sw.js. Публікуйте version.txt останнім або всі файли одним комітом. Сховище фінансових даних та відповіді Auth/API ніколи не кешуються service worker.
